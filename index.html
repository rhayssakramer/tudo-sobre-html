Hacks de HTML que Você Precisa Saber

1. O atributo data-*

Armazene dados customizados em elementos HTML. Perfeito para passar informações via HTML sem usar atributos estranhos.

<div data-user="123" data-name="João"></div>

2. Contenteditable

Transforme qualquer elemento em editável sem JavaScript complexo.

<div contenteditable="true">Clique para editar</div>

3. Atributo download

Faça o download de arquivo ao invés de navegar para ele.

<a href="arquivo.pdf" download>Baixar PDF</a>

4. Input com datalist

Crie autocomplete nativo sem JavaScript.

<input list="cores"><datalist id="cores">...

5. Details e Summary

Accordion nativo com <details> e <summary>.

<details><summary>Clique</summary>Conteúdo</details>

6. Defer e Async

Otimize o carregamento de scripts com async (paralelo) ou defer (após DOM).

<script src="app.js" defer></script>

01 · HISTÓRIA DO HTML

A jornada do HTML através dos tempos.

Criada por Tim Berners-Lee e publicada na década de 1990, o HTML (HyperText Markup Language) é a linguagem padrão para criação de páginas na web. Sua história remonta ao início da internet moderna e passou por diversas evoluções ao longo dos anos. É hoje a linguagem base para todos os sites na Internet.

📅 Origens e Primeiras Versões (1989 - 1995)

  • Em 1989, Tim Berners-Lee, cientista do CERN, propôs um sistema de hipertexto para facilitar o compartilhamento de informações entre pesquisadores.
  • Em 1991, ele criou a primeira versão do HTML, com 18 tags básicas, incluindo <p>, <a>, <h1>, <title>, <body> e <img>.
  • Em 1993, a primeira especificação formal do HTML foi publicada por Berners-Lee e o NCSA Mosaic popularizou a web.
  • Em 1995, surgiu o HTML 2.0, consolidando os padrões usados na época.

📈 Evolução e Padrões (1997 - 2004)

  • HTML 3.2 (1997): Introduziu suporte a tabelas, scripts e estilização via CSS.
  • HTML 4.01 (1999): Separou estrutura (HTML) da apresentação (CSS), tornando o código mais limpo.
  • XHTML (2000 - 2004): Tentou tornar o HTML mais rígido e baseado em XML, mas não foi amplamente adotado.

🚀 O Surgimento do HTML5 (2008 - Presente)

  • Em 2008, o HTML5 foi proposto pelo WHATWG e W3C, focando em interatividade e suporte a multimídia sem plugins como Flash.
  • O HTML5 foi oficializado em 2014, trazendo novidades como:
    • 🏷️ Tags semânticas (<header>, <article>, <section>, <footer>).
    • 🎬 Elementos multimídia nativos (<video>, <audio>).
    • 🎨 Canvas e SVG para gráficos dinâmicos.
    • ⚙️ APIs para geolocalização, armazenamento local e aplicações offline.
02 · O QUE É HTML?

A linguagem de marcação que constrói a web.

É uma linguagem de marcação utilizada na construção de páginas web/websites, no desktop ou mobile. HTML quer dizer "Hyper Text Markup Language" ou seja "Linguagem de Marcação de Hipertexto". O HTML é a base para todas as aplicações web que visualizamos.

⚠️ Atenção! HTML não é linguagem de programação. HTML baseia-se em marcações que dão significado aos elementos.

🏷️ Tags e Estrutura

O HTML baseia-se em Tags para definir o seu conteúdo. As Tags são delimitadas pelos sinais de < e > e definem o significado de um determinado elemento.

<p> Um parágrafo </p>
📌 Exemplo: Para definir um parágrafo no documento na página web, utiliza-se a tag p entre o sinal de maior e menor <p> e um texto. Tem-se ainda a tag de abertura <> e a tag de fechamento </>, que delimitam o conteúdo desse parágrafo.

🌐 O Papel do HTML

O HTML conta ainda com diversas outras tags que estruturam o documento, adicionando imagens, cabeçalhos, botões, elementos de interação com o usuário, como campos para digitação de texto, que poderão ser interpretados e apresentados para o usuário de forma amigável.

Um documento HTML é composto por diversas tags que em conjunto, definem a estrutura e o conteúdo da página, e também como ela deve ser lida, tanto por um ser humano, como por uma máquina que irá interpretar aquele documento, que é normalmente, um navegador da internet.

📌 Navegadores: Os browsers são software capazes de interpretar um documento HTML e gerar um resultado gráfico. E esse resultado é aquele que vemos quando abrimos um site no nosso navegador.

🎨 HTML + CSS + JavaScript

O HTML é responsável pela estrutura e na aparência visual contam como CSS "Cascading Style Sheets" e o JavaScript, duas outras linguagens empregadas na programação web, em conjunto com o HTML, para definir a aparência e o funcionamento das páginas.

💡 Dica: A documentação do HTML está no site w3schools.com.
03 · COMUNICAÇÃO CLIENT X SERVER

Cliente e servidor: duas partes que conversam.

O modelo Client x Server (Cliente x Servidor) é um dos fundamentos da computação em redes e do desenvolvimento web. Ele define como os dispositivos se comunicam na internet ou em sistemas distribuídos.

🔄 O Modelo

O modelo Cliente-Servidor divide a comunicação entre dois papéis principais:

👤 Cliente (Front-end)

  • Solicita informações ou serviços
  • Pode ser um navegador, aplicativo mobile ou qualquer dispositivo que consome dados
  • Quando você acessa um site, seu navegador é o cliente

🖥️ Servidor (Back-end)

  • Processa as solicitações do cliente e responde com dados necessários
  • Pode hospedar bancos de dados, APIs ou arquivos
  • Quando você acessa um site, o servidor do site retorna a página

📡 Fluxo de Comunicação

  1. O cliente envia uma requisição para o servidor (exemplo: "Quero acessar a página X").
  2. O servidor processa essa requisição, busca as informações necessárias e responde.
  3. O cliente recebe os dados e exibe para o usuário.
Cliente → (HTTP) → Servidor
Cliente ← (HTTP) ← Servidor

🔗 Tipos de Comunicação Cliente-Servidor

  • Requisições HTTP/HTTPS: Comunicação tradicional baseada em requisições e respostas.
  • WebSockets: Comunicação em tempo real bidirecional.
  • APIs REST ou GraphQL: Formas estruturadas de envio e recebimento de dados.
📌 Exemplo do dia a dia:
  • Você digita www.google.com no navegador
  • O navegador (cliente) envia uma solicitação para o servidor do Google
  • O servidor responde enviando a página inicial do Google
04 · O QUE SÃO PROTOCOLOS?

As regras que fazem a comunicação funcionar.

Protocolos são regras de comunicação. Na computação, um protocolo define como dois sistemas se comunicam, ou seja:

  • Como a mensagem é enviada
  • Como ela deve ser recebida
  • Em que formato
  • Em que ordem
  • O que fazer em caso de erro
💡 Analogia simples (vida real): Imagine uma conversa no WhatsApp: Idioma = Português, Estrutura = pergunta → resposta, Emojis, áudios, textos têm regras. Se alguém falasse japonês do nada, a conversa quebraria. 👉🏼 Protocolos são o "idioma" que computadores usam para conversar.

🔌 Principais Protocolos

  • HTTP (HyperText Transfer Protocol)
    • Protocolo da web
    • Usado em sites, APIs, sistemas web
    • Exemplo: GET /usuarios
  • HTTPS (HTTP Secure)
    • Versão segura do HTTP
    • Usa criptografia (SSL/TLS)
    • Protege: Senhas, dados pessoais, informações bancárias
  • TCP (Transmission Control Protocol)
    • Garante que os dados cheguem completos e na ordem correta
    • Usado "por baixo" do HTTP
  • IP (Internet Protocol)
    • Identifica quem envia e quem recebe
    • Exemplo: IP do cliente, IP do servidor
  • WebSocket
    • Comunicação em tempo real
    • Usado em: Chats, jogos online, notificações instantâneas
05 · REQUISIÇÃO

A mensagem que o cliente envia.

Uma requisição é a mensagem enviada pelo cliente. Ela contém:

  • Método HTTP
  • URL
  • Headers
  • Body (opcional)

🔧 Métodos HTTP mais usados

Método Função
GET Buscar dados
POST Criar dados
PUT Atualizar dados
DELETE Remover dados
PATCH Atualizar parcialmente 
GET /api/usuarios
06 · RESPOSTA

A mensagem que o servidor retorna.

A resposta vem do servidor para o cliente. Contém:

  • Status Code
  • Headers
  • Body (dados)

📊 Status Codes importantes

Código Significado
200 Sucesso
201 Criado
400 Erro do cliente
401 Não autorizado
403 Proibido
404 Não encontrado
500 Erro no servidor

08 · APIS

O garçom que leva o pedido até a cozinha.

A API é o meio pelo qual o cliente conversa com o servidor.

💡 Pense na API como: "O garçom que leva o pedido até a cozinha e traz o prato pronto."

🔗 Tipos de API

  • REST - Mais comum, baseado em HTTP
  • GraphQL - Query language moderna
  • SOAP - Legado, menos usado

📝 Exemplo prático: Login de usuário

1️⃣ Cliente envia:

{
  "email": "teste@email.com",
  "senha": "123456"
}

2️⃣ Servidor:

  • Valida dados
  • Confere no banco
  • Gera token

3️⃣ Servidor responde:

{
  "token": "abc123xyz"
}

4️⃣ Cliente:

  • Salva o token
  • Usa em requisições futuras
09 · NAVEGADORES

Os programas que interpretam o HTML.

Os navegadores (ou browsers) são programas que permitem acessar e visualizar páginas da web. Eles interpretam HTML, CSS e JavaScript para exibir os sites corretamente.

🌐 Principais Navegadores

🔵 Google Chrome

Criado pelo Google em 2008. Baseado no motor Blink e na engine V8 (JavaScript). Suporte a extensões e integração com serviços do Google.

🦊 Mozilla Firefox

Criado pela Mozilla em 2002. Utiliza o motor Gecko. Foco em privacidade e código aberto.

💙 Microsoft Edge

Substituiu o Internet Explorer em 2015. Baseado no Chromium (mesmo motor do Chrome). Integração com Windows e IA.

🍎 Safari

Desenvolvido pela Apple, exclusivo para macOS e iOS. Usa o motor WebKit. Otimizado para dispositivos Apple.

⚙️ Como um Navegador Funciona?

  1. O usuário digita um URL na barra de endereços.
  2. O navegador faz uma requisição HTTP/HTTPS ao servidor do site.
  3. O servidor responde com os arquivos da página (HTML, CSS, JavaScript).
  4. O navegador renderiza a página, aplicando estilos e executando scripts.
10 · APLICAÇÕES WEB

Sistemas que funcionam no navegador.

As aplicações web são sistemas acessados via navegador, sem necessidade de instalação no dispositivo do usuário. Elas utilizam a internet para funcionar e geralmente seguem o modelo Cliente-Servidor.

📌 Exemplos: Gmail, Google Drive, Netflix, Instagram, Twitter.

✨ Características das Aplicações Web

  • Acessíveis via navegador: Sem necessidade de download.
  • Multi-dispositivo: Funcionam em PCs, tablets e smartphones.
  • Facilidade de atualização: Alterações no servidor refletem para todos os usuários.
  • Escaláveis: Podem crescer para atender milhões de usuários.

🎯 Tipos de Aplicações Web

📄 Estáticas

Conteúdo fixo, sem interação dinâmica. Exemplo: Blogs simples e páginas institucionais.

🔄 Dinâmicas

Geram conteúdo personalizado com base na interação do usuário. Exemplo: Facebook, Gmail.

📱 Single Page Application (SPA)

Carregam uma única página e atualizam dinamicamente. Tecnologias: Angular, React, Vue.js.

⚡ Progressive Web App (PWA)

Funciona como site e pode ser instalado no dispositivo. Funciona offline. Exemplo: Twitter Lite.

⏱️ Tempo Real

Atualizam dados instantaneamente. Tecnologias: WebSockets, Firebase. Exemplo: WhatsApp Web.

11 · DISPOSITIVOS MÓVEIS

A computação que cabe na palma da mão.

Os dispositivos móveis são aparelhos portáteis que possuem capacidade de processamento, conexão à internet e interatividade por meio de telas sensíveis ao toque.

📌 Exemplos:
  • Smartphones (Android, iPhone)
  • Tablets (iPad, Galaxy Tab)
  • Smartwatches (Apple Watch, Galaxy Watch)
  • Dispositivos IoT (Alexa, Google Nest)

📱 Características dos Dispositivos Móveis

  • Portabilidade: Pequenos, leves e fáceis de transportar.
  • Conectividade: Wi-Fi, 4G, 5G, Bluetooth, NFC.
  • Sensores integrados: Câmera, GPS, acelerômetro.
  • Bateria recarregável: Independência de energia fixa.
  • Sistemas Operacionais próprios: Android (Google) e iOS (Apple).

🚀 Tipos de Aplicações para Dispositivos Móveis

🎯 Aplicações Nativas

Desenvolvidas para um SO específico. Linguagens: Kotlin, Java (Android) | Swift (iOS). Melhor desempenho, acesso direto a hardware.

🔀 Aplicações Híbridas

Código único para múltiplas plataformas. Tecnologias: Flutter, React Native, .NET MAUI. Boa performance e desenvolvimento mais rápido.

🌐 Aplicações Web Responsivas

Rodam no navegador sem instalação. Tecnologias: HTML, CSS, JavaScript. Se adaptam a telas menores.

⚙️ Progressive Web Apps (PWA)

Web apps com funcionalidades de apps nativos. Funcionam offline, enviam notificações. Exemplo: Twitter Lite, Spotify Web.

14 · CURIOSIDADES E DICAS

Fatos interessantes sobre HTML.

💡 Dica 1: HTML não é uma linguagem de programação, é uma linguagem de marcação. Ela define a estrutura do conteúdo, não a lógica.
📌 Dica 2: Você precisa de HTML + CSS + JavaScript para criar uma web moderna. HTML é a estrutura, CSS é a aparência, e JavaScript é o comportamento.
🎯 Dica 3: Todo site que você acessa começa com HTML. Mesmo aplicações web complexas (Google, Facebook, Netflix) têm HTML como base.
⚠️ Dica 4: Nunca coloque senhas ou informações sensíveis no HTML. Todo código HTML pode ser visto pelo usuário no navegador (inspecionar elemento).
📌 Dica 5: O HTML evolui constantemente. Novas tags e funcionalidades são adicionadas regularmente. Acompanhe a documentação oficial!

17 · ATIVIDADE PRÁTICA

Hora de colocar a mão na massa!

🎯 Tarefa: Crie seu primeiro arquivo HTML!

📋 Instruções:

  1. Abra um editor de texto (VS Code, Sublime, Notepad++, etc.)
  2. Crie um arquivo chamado meu-primeiro-site.html
  3. Copie e cole o código abaixo: 
    <!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Primeiro Site</title>
</head>
<body>
    <h1>Olá, Mundo! 👋</h1>
    <p>Esse é meu primeiro site em HTML!</p>
    <p>Estou começando minha jornada no desenvolvimento web.</p>
</body>
</html>
  4. Salve o arquivo e abra-o no navegador
  5. Parabéns! Você criou seu primeiro site em HTML! 🎉

🚀 Desafios Adicionais:

  • Adicione um parágrafo com seu nome e uma breve descrição
  • Adicione um link para sua rede social favorita
  • Mude o título da página (aquele que aparece na aba do navegador)
  • Adicione uma imagem (use um link de imagem online)
  • Use headings diferentes (<h2>, <h3>, etc.)
💡 Dica: Inspecione o código HTML de sites que você gosta! Clique com o botão direito → "Inspecionar" e veja como é feito!
